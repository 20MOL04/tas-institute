9.1 AUDIT ADMINISTRATIF
====================================================================

Questions à investiguer :

INSCRIPTION

- Comment un nouvel étudiant s'inscrit-il ?
- Qui collecte les informations ?
- Sur papier ou numérique ?
- Où sont stockées les données ?
- Combien de temps prend l'inscription ?
- Quels documents sont nécessaires ?
- Comment le paiement est-il enregistré ?
- Comment le reçu est-il produit ?
- Comment l'étudiant reçoit-il sa confirmation ?

MATRICULE

- Comment est généré le matricule ?
- Est-il unique ?
- Est-il centralisé ?
- Est-il enregistré dans une base ?
- Que se passe-t-il si l'étudiant perd son matricule ?
- Peut-on retrouver facilement un étudiant ?
- Les anciens matricules sont-ils conservés ?

ÉTUDIANTS

Informations potentielles :

- nom ;
- prénom ;
- photo ;
- téléphone ;
- email ;
- nationalité ;
- pays ;
- programme ;
- niveau ;
- groupe ;
- date d'inscription ;
- statut ;
- historique.

NOTES

- Où sont stockées les notes ?
- Qui les saisit ?
- Comment sont calculées les notes ?
- Comment sont produits les résultats ?
- Peut-on retrouver les notes d'un ancien étudiant ?
- Les données sont-elles sauvegardées ?

PHOTOS

- Où sont stockées les photos ?
- Téléphone ?
- WhatsApp ?
- ordinateur ?
- papier ?
- dossier individuel ?

CARTES SCOLAIRES

Observer le processus exact :

1. récupérer la liste ;
2. récupérer les photos ;
3. vérifier les noms ;
4. vérifier les matricules ;
5. préparer les cartes ;
6. imprimer ;
7. corriger les erreurs.

Mesurer le temps nécessaire.

REÇUS

- Comment sont produits les reçus ?
- Papier ?
- Excel ?
- autre ?
- Comment retrouver un paiement ?
- Que se passe-t-il en cas de perte ?
